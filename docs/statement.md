# Project Statement

## Problem Statement

Managing books and members manually in a library can be time-consuming and may lead to mistakes. A simple computerized system can help organize basic library activities.

## Project Scope

The project focuses on basic library management activities such as:

- Managing books
- Managing members
- Borrowing books
- Returning books
- Searching for books

## Target Users

The system is designed for:

- Library staff
- Students
- Library members

## High-Level Features

### 1. Book Management

- Add a new book
- View available books
- Search for a book

### 2. Member Management

- Add a new member
- View registered members

### 3. Borrow and Return

- Borrow a book
- Return a book
- Check whether a book is available
