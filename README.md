# Library Management System

## Introduction

The Library Management System is a basic Python project used to manage books, members, and library transactions.

## Features

- Add Book
- View Books
- Search Book
- Add Member
- View Members
- Borrow Book
- Return Book

## Technologies Used

- Python
- Visual Studio Code
- Git
- GitHub

## Modules

- books.py
- members.py
- transactions.py
- data.py
- utils.py
- main.py

## How to Run

Run the following command:

python main.py
